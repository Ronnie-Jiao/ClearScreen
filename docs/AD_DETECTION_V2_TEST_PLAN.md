# 广告识别 v2：检测范围、真机复测与回归清单

> 对应 `feature/ad-detection-v2`。这是一次 Android AccessibilityService 识别算法修改，并不代表三个截图中的广告已在真机验证成功。测试前需安装该分支重新构建的 APK，并确保无障碍服务确实处于已连接状态。

## 问题样本（2026-10-13）

| 样本 | 可观察的 UI | v2 检测路径 | 仍然存在的限制 |
| --- | --- | --- | --- |
| 中国移动，首页宽带全家享弹窗 | 半透明遮罩 + 大居中卡片 + 卡片右上方浮动 × | 关闭广告文本/资源 ID、邻近广告信号 + 高置信度手势 | 若 × 完全由图片绘制且不向无障碍树暴露节点，无法识别；不允许仅按坐标盲点 |
| 中国移动，「发口令 抢红包」开屏 | 右上角「3 跳过」倒计时 | 独立解析 Text/ContentDescription、倒计时数字变化稳定指纹、非 clickable 节点的受限手势 | 若整屏由 Canvas/SurfaceView 绘制且未暴露控件，依旧可能漏 |
| 天气页面的滴滴租车广告 | 浮层大卡片 + 上方圆形 × + 底部广告标识 | 「关闭」/× 节点 + 附近广告标识；或同一居中弹窗区域的广告信号 | 若广告标识和关闭图标在无障碍树不可见，无法仅凭屏幕像素做判断 |

## v2 改动概要

1. 仅监听与页面检测直接相关的窗口状态、窗口内容与窗口列表变化，避免 `typeAllMask` 无谓处理。
2. 首次窗口出现时额外在 220 / 600 / 1200 ms 做有界复查，处理 SDK 延迟渲染；内容变化事件每 100 ms 节流。
3. 将 Text 和 ContentDescription **分别规范化匹配**，兼容两者不一致或同时存在的广告按钮。
4. 有可点击控件先执行 `ACTION_CLICK`；若系统拒绝，只有显式广告动作、高置信度、屏幕右上紧凑区域才可 `dispatchGesture`。
5. 弹窗关闭 X 必须具备明确的广告资源 ID/标签，或同一附近区域/居中弹窗区域存在广告证据。不因背景页面其它角落存在「广告」就点击任意 X。
6. 对倒计时跳过使用不随「3→2→1」文本变化的尝试指纹，降低重复点击与误记成功概率。
7. 优先点击紧凑父控件；父控件过大时退回小节点和严格受控的点击策略，不在大型整屏父节点上直接点击。
8. 如果当前前台窗口已经切换到其它 App，不再检查或点击上一个 App 的后台节点。
9. 手势成功只表示操作已执行；事后仍看见相同控件记失败，切到无法验证的窗口记 `attempted` 而不虚构成功。

## 真机测试步骤

**先在每台设备上检查权限是否真实保持，服务可连接。** 当前某些 vivo / OriginOS 机型在 Android 16 下存在授权无法保持的问题，这与识别算法无关；无障碍服务没启动时无法进行命中率对比。

1. 打开净屏总开关，确认目标 App 没有被白名单排除，测试前关闭目标 App 使开屏重新触发。
2. 依次复现上方三个样本，每个场景至少 10 次：记录 **识别并正确关闭 / 未识别 / 误关闭正常 UI / 动作执行但没有生效**。
3. 特别验证「3跳过」到「2跳过」时没有被误记为跳过成功，也不会被连续点多次。
4. 无障碍关闭或净屏暂停后，三个场景均不应发生自动点击。
5. 在正常页面、设置页、搜索框、支付/登录/权限确认页分别出现关闭 X 或「跳过」字样时，确认不乱点。
6. 前台快速切换 App 后，不能发生迟到的滑动/点击动作落在新 App。
7. 30 分钟正常使用时关注电池耗电、卡顿、页面频繁重绘等副作用。
8. 真机完成后再讨论是否合并 `main`。


Debug 构建可通过 `adb logcat -s ClearScreenA11y:D *:S` 查看候选规则和动作结果；日志不应包含完整界面树或敏感输入。

## 为什么不直接使用 OCR / 图像全屏找 X

Android 无障碍节点和用户上传的截图并非同一种信息源。对于完全绘制在图片/Canvas/SurfaceView 中、没有暴露可访问节点的关闭按钮，**仅凭 AccessibilityNodeInfo 无法确保识别**。通过屏幕截图再用 OCR/视觉模型查找可能扩大权限范围、读取私人界面、增加延迟和误点风险。应先通过脱敏的节点诊断确认这些漏识别样本是否真的缺少节点，再评估可选、用户明确授权的图像识别方案。不得只因某个角落形似 X 就盲点。

## 发布判断

- 本 PR 为**待真机验证**的算法增强，不声称已解决所有广告类型。
- 验收第一指标是**正常 UI 误点击接近零**，第二指标才是广告处理命中率。
- 不自动读取或上传私密屏幕内容；不通过隐藏方式获取系统无障碍授权。
