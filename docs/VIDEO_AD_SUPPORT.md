# 视频平台广告识别｜第一阶段实现与真机验收

> 代码位置：\`android/app/src/main/java/com/clearscreen/prototype/backend/VideoAdRules.kt\` 和 \`ClearScreenAccessibilityService.kt\`。本功能属于 **Accessibility 节点点击增强**，不是播放器流量解密、视频片源修改或破解会员。提交不代表真机验证成功。

## 已支持的目标包名

| App | Android 包名 | 处理方式 |
| --- | --- | --- |
| 爱奇艺 | \`com.qiyi.video\` | 播放器内部广告跳过/关闭控件 |
| 腾讯视频 | \`com.tencent.qqlive\` | 同上 |
| 优酷 | \`com.youku.phone\` | 同上 |

采用**精确包名**而不是依靠“包含 video/qiyi”猜测；其他未列出的视频 App 使用原有通用开屏逻辑。

## 能做与不能做

### 可以尝试
- 明确显示 **「跳过广告 / 跳过此广告 / 跳过贴片广告 / 跳过视频广告 / Close ad / Skip ad」** 的可访问按钮。
- 广告区域内，位于画面右侧的简短 **「跳过 / Skip / 3 跳过」**，且**同一附近区域**有广告文字/广告 SDK 资源标记。
- 明确标为广告的 **「关闭广告 / 关闭贴片广告」** 控件。
- 横竖屏均按相对位置计算，不写死像素坐标；保留原来的延时扫描机制和重复点击约束。
- 控件可点击时优先 Accessibility \`ACTION_CLICK\`；只有证据充分、紧凑、屏幕角落的显式广告控件才可能使用受限手势。

### 明确不操作
- 播放器的 **「关闭 / × / 退出全屏 / 返回」**、播放 / 暂停、进度条、下一集、上一集、跳过片头片尾。
- 开通 VIP、升级会员、充值、购买广告免看权益、支付、订阅。
- **「5 秒后才能跳过」「广告剩余 15 秒」** 等不可点击倒计时；不会自动快进、模拟时长、调整系统时间。
- 闹钟、真实计时器、日程提醒与通知：延续 \`ProtectedUiPolicy\` 的安全屏障。
- 没有可访问“跳过/关闭”节点的 Canvas / SurfaceView / DRM 视频画面：节点算法无法凭空找到控件。**不能保证消除不可跳过的贴片广告**。

## 运行流程

\`\`\`text
视频平台前台窗口 → 当前总开关及 App 规则允许?
   ↓ 是
受保护的闹钟 / 提醒 / 系统页面排除
   ↓
无障碍节点捕获 → 视频平台专用识别（不走通用弹窗 X 点击）
   ↓
显式广告操作? ──是──> 控件紧凑、有安全点击目标 → 执行
   ↓ 否
普通跳过按钮? ──是──> 附近广告证据 + 右侧位置 → 执行
   ↓ 否
不操作，等待自然播放或下次页面事件
   ↓
动作后复核 + 本地日志
\`\`\`

## 真机回归矩阵（正式合并前必测）

| 设备与平台 | 场景 | 预期 |
| --- | --- | --- |
| vivo / OriginOS、Android 16 | 爱奇艺前贴片广告，显示「跳过广告」 | 控件可点时正确点击；不可点时不盲点视频区域 |
| 同上 | 腾讯视频前贴片广告，显示倒计时与“广告” | 到可跳过阶段再处理；倒计时未结束不自动点击 |
| 同上 | 优酷横屏播放器，中插广告 | 只操作明确广告按钮，不停止影片 |
| 同上 | 芒果 TV 全屏广告弹层，显示“关闭广告” | 只关闭该广告，不点击会员购买 |
| 四个平台 | 「跳过片头」「跳过片尾」「下一集」 | **零操作** |
| 四个平台 | 打开设置、选集、弹幕、清晰度、全屏退出 | **零操作** |
| 四个平台 | VIP 购买/支付弹窗 | **零操作** |
| 系统闹钟和计时器 | 视频广告出现同时提醒抢占前台 | 先保护提醒，禁止执行迟到手势 |
| 其他 App | 手机正常开屏广告 | 仍使用原有通用识别流程 |
| 四个平台 | 只有图片、Canvas 或 SurfaceView，没有无障碍控件 | 不承诺命中；由用户手动处理 |

每个真实广告场景至少测试 **10 次**，记录：广告是否确实提供跳过控件、可访问节点、点击接受情况、广告是否消失、误触与耗时。**准确率和误触率只能以真实设备数据为准。**

## 当前版本状态与限制

- 已写入代码和单元测试 \`VideoAdRulesTest.kt\`。
- **尚未完成 Android 完整 Gradle 编译、四个平台的实机测试**。
- 原有 \`getAppRule(packageName).skipEnabled\` 与白名单对视频 App 同样生效；本次没有新增“虚假的视频广告开关”。
- 视频服务往往动态更换广告 SDK 与控件名称，所以本功能是**安全增强，不是对四个平台全部广告的100%关闭保证**。
- 发布前仍需评估第三方视频服务条款和广告跳过相关法律风险。
