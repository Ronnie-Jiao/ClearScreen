# Android 应用商店合规核查

最后核查：2026-10-13。对象：净屏 Android 1.0.28（版本代码以本次 Release 构建检查为准）。本记录是代码与公开规则对照，不等于商店审核通过或法律意见。

## 已落实到代码和材料

- 首次启动先展示隐私政策；用户明确同意前，不读取启动器应用列表、系统无障碍状态、已有规则/记录或其他应用界面。无障碍服务即使被系统绑定，也在没有当前版本同意时停止读取和处理。
- 设置中可重看隐私政策、清空处理记录和撤回同意。撤回时停止无障碍界面处理并删除应用规则、记录和设置；不会擅自改变 Android 系统无障碍开关。
- 提供 HTTPS 公开政策页面：[净屏隐私政策](https://clearscreen-privacy-policy.buzzyorbit64.chatgpt.site)。公司主体及邮箱来自应用负责人确认。
- Release 移除互联网/网络状态、外部存储、悬浮窗、振动和忽略电池优化权限；关闭 Android 应用备份。仅查询带启动器入口的应用，不声明 `QUERY_ALL_PACKAGES`。
- 无障碍服务不声明手势能力；Android 11+ 的截图和 ML Kit OCR 用于本机识别，不保存截图或识别文字。
- 公开政策与应用内告知覆盖应用列表、无障碍界面、诊断信息、处理记录、Google ML Kit 的诊断行为、本地保存期限、撤回删除和联系渠道。
- Google ML Kit 官方资料说明 SDK 可能联系 Google 服务器并发送性能/使用指标；当前 Release 未声明 `INTERNET` 权限，但尚未对所有系统/设备路径做抓包验证，因此商店 SDK/个人信息表按“可能处理诊断指标”如实填报，不宣称绝无网络处理。

## 发布前仍需负责人提供/办理

1. 四个平台的企业开发者账号认证和主体证明材料；当前只录入了负责人确认的公司中英文名称及邮箱，未验证营业执照/统一社会信用代码。
2. 按主管部门和各平台要求办理/补填 APP 备案信息。工信部的 APP 备案通知要求应用主办者办理移动互联网应用程序备案；本仓库无法替企业完成实名和主管部门流程。
3. 按各商店当前控制台补齐软件著作权、应用分类、年龄分级、联系人、用户协议、个人信息清单及其他材料（以平台最新表单为准）。
4. 对净屏“自动关闭第三方应用广告”的核心行为取得各平台明确分类/预审意见。商店是否收录不由隐私弹窗或权限清理单独决定。
5. 由负责人确认目标年龄范围和未满14周岁用户的服务策略；若允许未满14周岁用户使用，需确认并实现符合要求的监护人同意流程，当前通用“同意并继续”按钮不能单独证明监护人身份或授权。
6. 由负责人审阅公开政策的主体、联系方式、信息处理描述和未成年人条款；若业务或 SDK 配置发生变化，先更新政策和版本同意机制。

## 当前结论

代码与公开隐私材料的可补缺项已处理；商店认证、APP 备案、各平台自检/预审和“自动关闭第三方广告”的可收录性仍未完成或确认。本次没有提交任何应用商店，也不能据此宣称“已通过四家商店审核”。
