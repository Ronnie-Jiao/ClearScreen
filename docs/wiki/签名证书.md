## 本次核验

- 从本机 Release 签名密钥库导出正式证书并提取公钥；证书 MD5、SHA-1、SHA-256 与当前 `app-release.apk` 的签名者信息一致。
- `apksigner verify --verbose --print-certs` 验证通过，APK 使用 v2 签名。
- 私钥和密码不应放入 Wiki、Git、聊天或截图；它们由项目单独的受限备份保存。
