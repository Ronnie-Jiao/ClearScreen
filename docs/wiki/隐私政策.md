## iOS Safari 扩展补充说明

净屏 iOS 版本通过 Safari Web Extension 处理网页广告，不使用 Android 无障碍能力，也不会读取、截图或点击其他 iPhone App 的界面。

只有用户在系统设置中启用净屏 Safari 扩展、在 Safari 扩展面板中打开过滤，并允许扩展访问相应网站后，网页脚本才会运行。脚本在本机临时读取当前网页中与按钮识别相关的文字、控件属性及布局信息，并可能点击同一广告区域内明确的“跳过广告”或“关闭广告”控件。图片/Canvas 广告、嵌入框架中的广告、未提供明确可点击按钮的广告或网页结构不兼容的页面可能无法处理。网页内容、网址、浏览历史和识别结果不保存、不上传；不使用 OCR、不请求广告服务器、不下载规则，也不记录处理次数。Safari 负责管理网站访问授权；用户可以关闭扩展开关或撤销网站权限。

Safari 扩展开关保存在 Safari 扩展本机存储中。卸载净屏会移除主应用和扩展；用户也可在 Safari 扩展面板中随时停用过滤。

当前公开隐私政策网页仅覆盖 Android。iOS 版本正式发布前，必须先把本节同步到公开政策页面并验证用户可访问；在完成前，不能把现有公开链接作为 iOS 隐私政策提交。

## iOS 系统网址过滤状态

iOS 首页中的“系统广告过滤”目前只是未接入能力的状态展示；当前版本不会通过 Apple URL Filter 拦截其他 App 的网络请求，也不会把该能力记录为已启用或已处理。后续若接入 iOS 26 系统 URL Filter，必须在发布前补充说明过滤规则来源与更新、Bloom 预过滤数据、PIR/Privacy Pass 查询流程、必要的服务端处理和保留期限，并更新公开隐私政策。Apple 的设计旨在让 PIR 查询不暴露具体查询的网址，但应用仍需如实说明过滤功能及服务依赖。

## 1. 同意前与无障碍服务

首次使用时，净屏先展示本政策。同意前，应用不读取可启动应用列表、无障碍授权状态、旧版应用规则和处理记录，也不读取其他应用界面。即使 Android 系统提前连接了净屏的无障碍服务，该服务在取得当前版本同意前也不会检查其他应用的事件、窗口或截图。

只有用户同意本政策、在 Android 系统设置中开启无障碍服务，并同时开启净屏总开关和目标应用规则后，净屏才会为该目标应用识别明确的广告跳过或关闭控件。无障碍服务可能接触当前应用标识和界面中可访问的文字、控件标识及布局信息；Android 11 及以上还可能截取当前屏幕，用于本机文字、图形及按钮边界识别。对已确认但点击无效的广告按钮，净屏可能重新核对后向同一可点击按钮中心补发一次短触摸。没有对应按钮节点时，除中国移动“55GB大流量卡 / 39元 + 40GB云盘”的限定开屏规则，还可能在两张截图均确认同一全屏广告、明确关闭文字和独立按钮边界，且当前窗口未被遮挡后向该按钮中心短触摸一次；不按普通叉号或未知位置触摸，不拖动、不长按。截图和识别出的界面文字仅在内存中处理，不保存为文件，也不会通过净屏上传。

## 2. 处理的信息、用途和期限

| 信息 | 用途 | 存储位置与期限 |
|---|---|---|
| 可启动应用的名称、包名和图标 | 显示应用列表、配置逐应用规则 | 应用列表只在使用时读取；规则保存在本机，直到删除规则、撤回同意或卸载应用 |
| 当前前台应用标识、可访问控件信息、支持时的本机截图/OCR结果 | 在用户开启的规则范围内识别广告控件 | 仅在内存中短暂处理；不保存截图或识别文字 |
| 处理记录：目标应用包名、规则编号、类型、结果、时间 | 展示处理历史和诊断 | 默认7天；可选关闭、1天、7天或30天，最多5000条。选“关闭记录”会停止写入并清理已有记录 |
| 用户主动检查更新时发出的网络请求 | 获取 GitHub 上的公开版本号和更新说明 | 净屏不保存请求；GitHub 会收到 IP 地址等标准网络请求信息。请求不包含应用列表、处理记录、屏幕内容或账号信息 |
| 设备品牌、安装来源、净屏首次安装/更新时间、签名证书指纹、无障碍/后台状态 | 在本机显示故障诊断信息 | 仅在应用运行期间读取和显示；净屏不把这些信息写入服务器 |
| 当前政策版本和同意时间 | 记录是否同意当前政策版本 | 保存在 Android 应用私有空间；撤回同意时删除 |

在用户主动从净屏打开自启动或后台设置后，如果厂商未开放可用的状态读取接口，且用户已开启无障碍服务，净屏会短时定位受信任系统设置中净屏自身的项目，只读核对明确的开关状态。此项本机权限核验不要求开启广告处理总开关，不自动操作设置、不截图，也不保存或上传系统页面文字、其他应用权限或节点对象；离开引导、服务断开、撤回同意或超过时限后停止并丢弃结果。无法明确归属或核验的项目仍保留未知状态。

如果设备中已有旧版本产生的本地数据，同意前净屏不会读取这些数据；同意后会按本政策在本机继续使用。用户也可以撤回同意并清除规则、记录和设置。

## 3. 第三方组件与网络

净屏集成 Google ML Kit 中文文字识别组件。输入图片和识别结果在设备端处理，不发送给 Google。Google 的[Android SDK 数据披露说明](https://developers.google.com/ml-kit/android-data-disclosure)列明组件可能处理设备/应用版本、安装标识、功能配置、性能指标、使用事件和错误码；[服务条款](https://developers.google.com/ml-kit/terms)还说明 ML Kit 可能联系 Google 服务器获取错误修复、模型更新和硬件兼容信息，并向 Google 发送性能与使用指标。Android 应用声明 `INTERNET` 权限，以支持用户主动检查更新。只有用户点按“检查更新”时，净屏才向 GitHub 公共 Releases 接口查询版本号和更新说明；GitHub 会收到 IP 地址等标准请求信息。该请求不携带应用列表、处理记录、屏幕内容或账号信息，净屏不在后台自动检查，也不保存请求或返回的更新说明。净屏自身不会上传截图或 OCR 识别结果。Google ML Kit 的网络行为仍可能按其说明处理诊断/使用指标，应用商店 SDK 信息披露应如实填写。

净屏不接入账号、广告、独立统计、推送或支付服务，也没有自建账号/广告服务器；GitHub 仅提供用户手动检查更新时使用的公开版本信息，Google ML Kit 诊断/使用指标按本节说明处理。打开本政策网页时，浏览器会访问网页托管服务；网页不设置跟踪 Cookie，也不嵌入分析脚本。网页托管基础设施可能按其规则处理提供网页所必需的网络请求信息，这与净屏 Android 应用的数据处理相分离。

## 4. 存储、安全和共享

应用规则、处理记录和同意记录保存在 Android 应用私有空间，不进行云端同步；当前 Android 应用关闭系统备份。净屏不向我们或其他第三方提供上述应用内数据。无障碍服务处理的屏幕内容不保存、不上传。

## 5. 用户权利和删除

Android 用户可以在“设置 > 隐私与数据”中清空处理记录，或选择“撤回同意并删除”。撤回后，净屏停止处理其他应用界面，并删除本机应用规则、处理记录和设置。撤回不会替用户改变 Android 系统中的无障碍开关；如需关闭该开关，请在系统设置中操作。卸载净屏会删除应用私有数据。用户也可以通过本政策末尾的邮箱提出查询、更正或删除请求。

## 7. 政策更新
